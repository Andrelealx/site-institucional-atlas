# Comece aqui — Site Institucional Atlas (Método Blueprint)

Este projeto já está documentado seguindo o Método Atlas Blueprint. A pasta `/docs` é a fonte de verdade e está preenchida com os dados da Atlas.

## Como disparar no Claude Code

Abra o terminal dentro desta pasta e rode:

```
Leia o arquivo AGENTS.md e os arquivos da pasta docs e execute exatamente o que eles pedem: construa o site institucional da Atlas seguindo a documentação, e ao final atualize docs/09-tarefas.md, docs/10-registro-de-alteracoes.md e docs/12-status-do-projeto.md.
```
