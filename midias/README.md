# Pasta de Mídias

Organize aqui os materiais do cliente.

## Estrutura sugerida

- `/logo`: logotipo e variações.
- `/banners`: artes principais e banners.
- `/fotos`: fotos da empresa, equipe, produtos e serviços.
- `/videos`: vídeos e reels autorizados.
- `/social`: prints, posts e materiais de redes sociais.

## Regras

- Não usar imagem sem autorização.
- Otimizar imagens para web.
- Criar versões em WebP quando possível.
- Usar textos alternativos para SEO e acessibilidade.
